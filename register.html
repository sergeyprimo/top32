📊 Синхронизация с Google Таблицей турнира

Вставьте ссылку на веб-приложение Google Apps Script (Web App URL вида https://script.google.com/macros/s/.../exec). Новые заявки и статусы допуска будут автоматически синхронизироваться!

📋 Код Google Apps Script для автоматической синхронизации

Этот код позволяет Google Таблице отдавать список всех зарегистрированных участников прямо в эту админ-панель.

Инструкция по обновлению (занимает 1 минуту):
  1. В вашей Google Таблице откройте меню: Расширения (Extensions) → Apps Script.
  2. Нажмите синюю кнопку «Скопировать код скрипта» выше, выделите весь старый код в редакторе (Ctrl+A), вставьте новый (Ctrl+V) и сохраните (дискета 💾 или Ctrl+S).
  3. Справа вверху нажмите синюю кнопку Развернуть (Deploy) → Управление развертываниями (Manage deployments) → значок ✏️ (Карандаш) → в поле «Версия» выберите Новая версия (New version) → нажмите Развернуть (Deploy).
  4. Готово! Теперь при открытии панели или нажатии «🔄 Синхронизировать» все заявки мгновенно загружаются сюда.
🔒 Режим судьи: Управление категориями доступно только главному администратору.
